## Project Overview

This repository implements zero-shot and few-shot texture anomaly detection methods. The project compares two approaches:

1. **Zero-shot approach** (`code/src/main.py`): Uses pretrained Wide ResNet50 without any training data
2. **Two-stage approach** (`train_simclr.py` + `code/src/datasets/main_inference.py`): Uses SimCLR contrastive learning pre-training on MobileNetV3, then inference with dual scoring

## Common Commands

### Zero-shot inference (no training required)
```bash
cd code/src
python main.py --save_path ./result
```

### Two-stage approach: Step 1 - SimCLR pre-training
```bash
python train_simclr.py
```


## Architecture Overview

### Zero-shot Approach (`code/src/main.py`)
- Uses `wide_resnet50_2` pretrained on ImageNet
- Extracts features from `layer2[3]` via forward hook
- Applies k-NN distance scoring (K=400) for anomaly detection
- Pure internal self-comparison - no training data needed

### Two-stage Approach (`code/src/datasets/main_inference.py`)
- **Training**: SimCLR contrastive learning on all normal samples
- **Backbone**: MobileNetV3 Large (lighter than ResNet)
- **Feature extraction**: Layer 6 of MobileNetV3
- **Dual scoring**:
  - Internal homogeneity: k-NN distance within test image
  - External prototype: Distance to Memory Bank of normal features
  - Combined with `lambda_weight` (default 0.5, adjusted per defect type)
- Memory Bank limited to 2000 prototypes for 60 FPS inference

## Key Implementation Details

### GPU Acceleration
- Distance calculations use `torch.cdist()` for GPU acceleration
- Score computation in `calc_score_gpu()` and `calc_dual_score_gpu()` uses einops rearrangement
- Never use sklearn's NearestNeighbors for feature distances - it's CPU-only and slow

### Score Map Processing
- `cut_surrounding=32`: Removes padding artifacts from convolutions
- `gaussian_filter(sigma=4)`: Smooths score maps before visualization
- Image-level score: mean of top-10 pixel scores (not max) for robustness

### Dynamic Lambda Adjustment
In `main_inference.py`, lambda weight is adjusted per defect type:
- Structural defects (tiaosha, fangyan): `lambda=0.01` (trust internal comparison)
- Color/coverage defects (youwu, etc.): `lambda=1.0` (trust external Memory Bank)

## Model Weight Locations

- Zero-shot: Uses torchvision pretrained weights (automatic)
- Two-stage: `code/src/datasets/weights/mobilenet_v3_simclr_all_classes.pth` (generated by train_simclr.py)
